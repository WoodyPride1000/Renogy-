# Renogy チャージコントローラー 高信頼性バッテリーロガー 設計書

## 1. システム概要
本システムは、Renogy ソーラーチャージコントローラーの稼働データを長期間にわたり安全に記録するための、低消費電力・高信頼性データロガーである。
従来の「SDカードへの直接・逐次書き込み」で発生する電源電圧変動によるFAT32ファイルシステム破損を完全に回避するため、**外付けI2C EEPROM（384KB）をリングバッファとして使用**し、通常時はバイナリ形式でデータを蓄積する。SDカードへの書き込みは、プッシュボタン押下またはシリアルコマンド送信による「一括ダンプ（フラッシュ）時のみ」に限定する。

### 主な仕様
- **記録間隔**: 1分間隔（RTC DS3231基準）
- **ストレージ容量**: 384KB（3Mbit = 128KB × 3チップ）
- **レコードサイズ**: 27バイト / 件（バイナリ構造体）
- **最大保存件数**: 約14,563件（1分間隔で **約10.1日分** の連続記録が可能）
- **メモリ管理方式**: リングバッファ方式（満杯時は先頭アドレス `0x00000` に戻り自動上書き）
- **データ回収方式**: プッシュボタン押下 または シリアルコマンド（`DUMP`）によるCSV一括出力

### 3.1 Arduino UNO ピン割り当て一覧
| Arduino ピン | 接続先 | 信号名・役割 | 備考 |
| :--- | :--- | :--- | :--- |
| **D2** | MAX3232 (TX) | `RENOGY_RX` | SoftwareSerial 受信 |
| **D3** | MAX3232 (RX) | `RENOGY_TX` | SoftwareSerial 送信 |
| **D4** | タクトスイッチ | `BUTTON_PIN` | `INPUT_PULLUP`（押下時 `LOW`） |
| **D10** | XD-204 シールド | `SD_CS_PIN` | SDカード チップセレクト |
| **D11** | XD-204 シールド | `MOSI` | SPI データ出力 |
| **D12** | XD-204 シールド | `MISO` | SPI データ入力 |
| **D13** | XD-204 / 内蔵LED | `SCK` / `LED_PIN` | ステータス表示（※SPI通信と兼用） |
| **A4 (SDA)** | 24FC1025 (×3) / RTC | `I2C SDA` | 4.7kΩでVCCへプルアップ |
| **A5 (SCL)** | 24FC1025 (×3) / RTC | `I2C SCL` | 4.7kΩでVCCへプルアップ |
| **5V / GND** | 各モジュール・IC | 電源ライン | 各IC直近に0.1µFパスコン配置 |

### 3.2 外付けEEPROM（24FC1025 × 3個）アドレス設定とメモリマップ
24FC1025は1チップ内に2つの64KBブロック（A16ビットで切替）を持つため、I2Cデバイスアドレスは下位ビット（A16）を含めて以下のようにマッピングされる。

| チップ番号 | ピン1 (A0) | ピン2 (A1) | ピン3 (A2) | ピン7 (WP) | I2Cアドレス (7bit) | 論理アドレス範囲 | 容量 |
| :---: | :---: | :---: | :---: | :---: | :---: | :--- | :---: |
| **EEPROM #1** | `GND` | `GND` | `VCC` | `GND` | `0x50` / `0x51` | `0x00000` 〜 `0x1FFFF` | 128KB |
| **EEPROM #2** | `VCC` | `GND` | `VCC` | `GND` | `0x52` / `0x53` | `0x20000` 〜 `0x3FFFF` | 128KB |
| **EEPROM #3** | `GND` | `VCC` | `VCC` | `GND` | `0x54` / `0x55` | `0x40000` 〜 `0x5FFFF` | 128KB |

※ **注意（24FC1025の仕様）**: 24FC1025は **ピン3（A2）を必ず `VCC` に接続** する必要がある（`GND` に落とすと動作しないため注意）。ピン7（WP: Write Protect）は書き込み許可のため `GND` に直結する。

## 4. データ構造仕様
### 4.1 EEPROM保存用 バイナリ構造体（27バイト）

```text
struct LogRecord {
  uint16_t year;      // 2 bytes: 西暦 (例: 2026)
  uint8_t  month;     // 1 byte : 月 (1-12)
  uint8_t  day;       // 1 byte : 日 (1-31)
  uint8_t  hour;      // 1 byte : 時 (0-23)
  uint8_t  minute;    // 1 byte : 分 (0-59)
  uint8_t  second;    // 1 byte : 秒 (0-59)
  float    batV;      // 4 bytes: バッテリー電圧 [V]
  uint8_t  soc;       // 1 byte : バッテリー残量 [%]
  uint16_t pvW;       // 2 bytes: ソーラー発電電力 [W]
  float    pvV;       // 4 bytes: ソーラーパネル電圧 [V]
  float    pvA;       // 4 bytes: ソーラーパネル電流 [A]
  float    chipTemp;  // 4 bytes: マイコン内蔵温度 [℃]
};
```
### 4.2 SDカード出力 CSVフォーマット
ファイル名: datalog.csv（追記モード O_APPEND）
ヘッダー行: datetime,batV,soc,pvW,pvV,pvA,chipTemp
データ行例: 2026-11-14 16:30:00,13.40,85,120,18.50,6.48,24.5

## 5. シリアルコマンド仕様（メンテナンス機能）
PCとUSB接続し、シリアルモニタ（ボーレート: 9600 bps / 改行コード: LF または 両方）から以下のコマンドを受け付ける。
コマンド	入力例	機能説明
SET:YYYY,MM,DD,HH,MM,SS	SET:2026,11,14,16,30,00	RTC（DS3231）の現在時刻を指定した日時に強制校正する
TIME	TIME	RTC（DS3231）の現在時刻をシリアルモニタへ出力する
DUMP	DUMP	プッシュボタン押下時と同様に、EEPROM内の全データをSDカードへ一括書き出しする
## 6. ファームウェアソースコード


### 実装時の重要メモ（設計書 3.2 補足）
24FC1025のデータシート仕様上、**ピン3（A2）は必ず `VCC`（5V）に接続**してください（A2をGNDに落とすとチップが応答しません）。コード内のアドレス計算式は、この配線仕様に合わせて設計されています。
